# Связанный путь улучшения · Alpha 0.15

1. Найти состав в «Командах». В карточке результата у каждого участника есть «Оптимизировать билд».
2. Состав, профили союзников и параметры болванок переходят в поиск сетов. По результату можно перейти к предметам выбранных наборов; режим «Комбинация» использует общий инвентарь.
3. В «Оценке реликвий» ввести свои 5★ предметы, отметить текущие, сравнить A/B и оценить реролл.
4. «Передать текущий билд в команду», затем «Вернуться к команде» и повторить симуляцию. Контекст фиксирует найденный состав кором; для повторного подбора состава можно изменить кор и пул.

Наверху есть общий маршрут, портреты участников и цель команды. Конфиг конуса и надетые предметы сохраняются отдельно для каждого персонажа; инвентарь общий. Прежний сохранённый билд остаётся билдом своего персонажа. Настройки хранятся локально в браузере. Существующий JSON-экспорт инвентаря доступен в «Комбинации».

## Оценка предметов

Балл = сумма `значение сабстата / максимальный единичный ролл × вес`. Профиль по роли — отправная точка; веса редактируются. «Оценить полезность статов в бою» добавляет по одному максимальному роллу каждого свойства к текущим статам и вычисляет изменение общего урона при неизменных сценарии и seed. При отсутствии полного комплекта используются сохранённые статы команды. Эти локальные веса можно применить к оценке реликвий.

Потолок качества — **точный максимум линейного балла**, не максимум боевого урона. Сет и основной стат фиксированы, уровень потолка +15, четыре разных разрешённых сабстата, четыре начальные строки и пять усилений. Потолок получается как сумма четырёх наибольших допустимых весов плюс пять наибольших весов. Основной стат исключён из пула сабстатов. Капы критов, основные статы и пороги скорости в линейном балле не учитываются; их последствия можно проверить боевым A/B.

Проверяется общий бюджет роллов, число строк, доступные величины роллов и округление экрана. Нельзя независимо поставить по шесть усилений на каждую строку. При неоднозначных округлениях возможны несколько распределений; число начальных строк указывает пользователь.

## Реролл

Реролл доступен для +15, сохраняет основной стат, набор и типы четырёх сабстатов. Три начальные строки оставляют четыре усиления, четыре строки — пять. Рассчитываются лучший балл этих типов, вероятность превзойти введённый балл и ожидаемый выигрыш с возможностью оставить старый результат.

Вероятности **условные**: каждая из четырёх строк и каждый из трёх размеров ролла предполагаются равновероятными и независимыми, включая начальные значения. Перебираются распределения усилений с мультиномиальными вероятностями и суммы размеров роллов с триномиальными вероятностями. Это не подтверждённая серверная таблица RNG. Результат не оценивает цену Variable Dice и не является обещанием прироста урона.

Источники механики: [Prydwen — Relic Stats](https://www.prydwen.gg/star-rail/guides/relic-stats), [официальное обновление 3.0 — Variable Dice](https://hsr.hoyoverse.com/en-us/news/127987?type=activity).

## Боевое сравнение и перенос

Для A/B нужны шесть текущих предметов. Меняется один слот, остальные предметы, союзники, длительность, число целей и seed одинаковые. Статы вычисляются через `sheetWithoutSets`; бонусы наборов исполняются в командном движке через `equipment`, без двойного добавления. Поддерживаются и смешанные предметы, включая 3+1 и разные планарки: активируются только реально собранные бонусы. Поиск сетов по-прежнему перебирает 4-предметные и 2+2 комбинации. Неподдержанные наборы и неполные комплекты дают пояснение вместо недостоверного результата.

Персонаж должен быть ур. 80. Передаются постоянные характеристики конуса; условный пассив конуса не исполняется. Действуют все ограничения существующего симулятора, включая отсутствие проверки выживаемости. Локальная чувствительность не доказывает глобальный оптимум ротации или билда.

| Ранний | Сюжет и открытый мир |
| Начальный | MoC 36 / PF 12 / AS 12 |
| Средний | Starward |
| Высший | Арбитраж аномалий 12 |

В карточке персонажа → «Характеристики» доступны редактируемые ориентиры каждого тира. Начальные значения определены по роли и не являются проверенными индивидуальными требованиями контента. Условия Starward, Арбитража и конкретные противники не моделируются тренировочными болванками. Числа не гарантируют прохождение. Для ранней игры это направление развития, а не требование иметь статы ур. 80 во время сюжета.

Проверки: `node scripts/verify-relic-lab.cjs`, `node scripts/verify-journey.cjs`; существующие проверки команд, сетов и одиночного оптимизатора также сохраняются.
